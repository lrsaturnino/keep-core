# F-07 -- Non-atomic WalletRegistry upgrade is front-runnable

**Severity:** Medium
**Location:** `solidity/ecdsa/contracts/WalletRegistry.sol:435`

The proxy admin must call `upgradeToAndCall` (atomic). A two-step `upgradeTo` + `initializeV2` leaves a window where an attacker can call `initializeV2` first and set a malicious Allowlist address.

**See also:** `vuln-0004.md` for detailed exploit walkthrough.
