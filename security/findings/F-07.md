# F-07 -- `approveDkgResult()` does not re-validate the result

**Severity:** Medium
**Location:** `solidity/ecdsa/contracts/WalletRegistry.sol`

After the challenge period, `approveDkgResult()` finalises a DKG result without re-running `EcdsaDkgValidator`. If no one challenges during the window, a malformed result is approved. The gap is partially mitigated by economic incentives for challengers, but there is no cryptographic safety net at approval time.
