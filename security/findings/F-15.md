# F-15 -- G2 square root exponent not cross-checked

**Severity:** Low / Informational
**Location:** `pkg/altbn128/altbn128.go:272`

The hardcoded exponent in `sqrtGfP2()` for G2 point decompression should be formally verified against the BN256 field modulus. An incorrect exponent would produce wrong public key decompression results.
