# F-15 -- G2 square root exponent not cross-checked

**Severity:** Low / Informational
**Location:** `pkg/altbn128/altbn128.go:296`

The hardcoded exponent in `sqrtGfP2()` for G2 point decompression should be formally verified against the BN256 field modulus. An incorrect exponent would produce wrong public key decompression results.

## Verification

**Status:** Investigated / Remediated (test added)
**Verified against:** `pkg/altbn128/altbn128.go:296`

```go
var exp = bigFromBase10("14971724250519463826312126413021210649976634891596900701138993820439690427699319920245032869357433499099632259837909383182382988566862092145199781964622")
```

**Mathematical verification:** The comment claims the exponent equals `(p^2 + 15) / 32` where `p` is the BN256 field modulus. Direct computation confirms this:

```python
p = 21888242871839275222246405745257275088696311157297823662689037894645226208583
(p**2 + 15) // 32 == 14971724250519463826312126413021210649976634891596900701138993820439690427699319920245032869357433499099632259837909383182382988566862092145199781964622
# True; (p^2 + 15) % 32 == 0 (divides exactly)
```

**The constant is correct.** The existing `TestCompressDecompressGivesSameG2Point` implicitly tests it (100 random G2 round-trips would all fail if the exponent were wrong).

## Fix Applied

Added `TestSqrtGfP2Exponent` to `pkg/altbn128/altbn128_test.go` to make the correctness assertion machine-checkable and explicit.
