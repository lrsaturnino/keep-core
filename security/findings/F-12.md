# F-12 -- Metrics endpoint is unauthenticated

**Severity:** Low / Informational
**Location:** `pkg/clientinfo/clientinfo.go:43`, default port 9601

No authentication. Exposes connected peer identities, addresses, and RPC health state to any host that can reach the port. Assists targeted P2P attacks and network topology reconnaissance.
