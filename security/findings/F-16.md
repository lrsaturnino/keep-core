# F-16 -- BLS aggregation does not enforce distinct signers

**Severity:** Low / Informational
**Location:** `pkg/bls/bls.go:31`

The `Aggregate()` function performs plain point addition without deduplicating signers. Correctness relies on callers enforcing uniqueness; there is no internal guard.

## Verification

**Status:** CONFIRMED
**Verified against:** `pkg/bls/bls.go:31`

Both `AggregateG1Points()` and `AggregateG2Points()` iterate over input slices and call `result.Add(result, point)` with no deduplication. A duplicate point or signer key included twice is counted twice, enabling rogue-key or signature-multiplication attacks if callers fail to enforce uniqueness upstream.
