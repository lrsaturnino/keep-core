# F-08 -- Post-TIP-092 slashing is symbolic (no token transfer)

**Severity:** Medium
**Location:** `solidity/ecdsa/contracts/Allowlist.sol:200`

`staking.seize()` emits an event but transfers no tokens. Economic penalties depend entirely on DAO governance calling `requestWeightDecrease()`. Attack-cost models based on token slashing (e.g., from audit reports or v1 documentation) do not apply to the current v2 deployment.
